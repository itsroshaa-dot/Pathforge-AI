# Pathforge-AI
PathForge AI: a multi-agent, AI-powered learning platform that analyzes skill gaps, builds personalized learning paths, and adaptively tracks progress. Built for PromptWars × RTC.
PathForge AI
An AI-powered personalized learning platform that finds your skill gaps, builds your
learning path, and adapts as you grow.
Built solo in 4 hours for PromptWars x RTC, organised by Rathinam Technical Campus.
Overview
Most learners know where they want to get to, but not what they are missing or what to study next.
PathForge AI closes that gap. It compares a learner's current skills against their target goal,
generates a step-by-step roadmap tailored to them, and keeps updating that roadmap as they make
progress.
Problem Statement
Design an AI-powered learning platform that supports:
• Skill gap analysis
• Personalized learning paths
• Multi-agent AI collaboration
• Adaptive progress tracking

How It Works
Specialized AI agents handle analysis, path planning, and progress
evaluation.
Updates the learning path as the learner completes topics and improves.
1. Learner enters current skills and target goal
2. Skill Gap Agent -> finds what is missing
3. Path Planner Agent -> builds a personalized roadmap
4. Progress Tracker Agent -> monitors progress and adapts the path
5. Updated roadmap is shown to the learner
